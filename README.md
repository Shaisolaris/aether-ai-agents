# Aether

AI agent platform site for distributed agent orchestration.

**[Live Demo](https://shaisolaris.github.io/aether-ai-agents/)**

## Features

- Agent catalog with capability cards
- Model provider sections
- Pipeline visualization sections
- Pricing and CTA flows

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
